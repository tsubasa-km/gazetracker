# gazetracker: Web カメラ視線トラッカー (OBS オーバーレイ対応)

Web カメラだけで視線を推定し、OBS のキャプチャーボード映像に視線マーカーを重ねます。
Splatoon など、Switch の映像を入力切替で見ながらプレイする用途向けです。

## 構成

| 部品 | 使用技術 | 役割 |
|---|---|---|
| 顔・虹彩検出 | MediaPipe Face Landmarker (CPU) | 478 点の顔ランドマーク、虹彩、頭部姿勢 |
| 視線回帰 | scikit-learn (Ridge) | 左右の虹彩位置の 2 次多項式 + まぶたの開き + 頭部姿勢と距離の積 → 画面座標 (0〜1 に正規化) |
| 平滑化 | One Euro Filter | ジッタ除去 |
| 配信 | websockets + 標準 http.server | OBS ブラウザソースへ座標を送る |
| オーバーレイ | 透過 HTML/Canvas | リング + 軌跡を描画 |
| 記録 | JSONL | タイムスタンプ付き視線ログ (後で解析可) |

## セットアップ (初回のみ)

1. Python 3.11 をインストール (3.12 でも可)
2. このフォルダで `setup.bat` をダブルクリック
   仮想環境の作成、ライブラリのインストール、モデル (約 3.6MB) のダウンロードを行います

## 起動方法

| 方法 | 手順 | 備考 |
|---|---|---|
| exe | `dist\GazeTracker\GazeTracker.exe` をダブルクリック | Python 不要。フォルダごと別 PC にコピーして使える。プロファイル・ログ・設定は exe と同じフォルダに保存される |
| pyw | `setup.bat` を一度実行してから `GazeTracker.pyw` をダブルクリック | コンソール窓なしで起動。`.venv` の Python を自動で使う |
| bat | `app.bat` | コンソール窓付き。エラーを見たいときに |

exe を自分で作り直すときは `setup.bat` の後に `build_exe.bat` を実行します (数分、約 370MB)。ビルドの最後に自動で署名されます。

### 別の PC で使う (署名と証明書)

exe は自己署名のコード署名証明書 (`CN=GazeTracker Self-Signed`) で署名されています。

1. `dist\GazeTracker` フォルダと `cert` フォルダを相手の PC にコピーする
2. 相手の PC で `cert\install_cert.bat` を**管理者として実行**する
   証明書が「信頼されたルート証明機関」と「信頼された発行元」に登録され、exe のプロパティ → デジタル署名 が有効になります
3. 初回起動で SmartScreen の青い画面が出たら「詳細情報」→「実行」を一度だけ押す

補足:
- 自己署名なので、証明書を登録しても SmartScreen の初回警告は出ることがあります (Microsoft 側の評判が無いため)。これを確実に消すには認証局発行の有料コード署名証明書 (年数万円) が必要で、その場合は `cert\sign.ps1` の `-Subject` をその証明書に合わせれば同じ手順で署名できます
- 署名の秘密鍵はこの PC の証明書ストア (ユーザー → 個人) にあり、ファイルには出していません。別の PC でビルドと署名をする場合は `certmgr.msc` から秘密鍵つき (.pfx) でエクスポートして持っていくか、その PC で `sign_exe.bat` を実行して新しい証明書を作ります (その場合は配布先で証明書の再登録が必要)
- 登録を取り消すには `cert\uninstall_cert.bat` を管理者として実行
- 署名にはタイムスタンプが付くので、証明書の有効期限 (2031-09) を過ぎても署名済みの exe は有効なままです

## 使い方 (GUI)

起動すると操作パネルが開きます。

1. 左の「設定」でプロファイル名 (環境ごとに `home` / `office` など)、カメラ、カメラ解像度、キャリブ表示モニターを選ぶ
   - カメラはデバイス名で一覧に出る。「このカメラの映像を確認」で右側に映像が出るので、自分の顔が正面から映るものを選ぶ
   - 「モニターに番号を表示して識別」を押すと各画面の中央に番号が 3 秒出る。Switch を映すモニターの番号を選ぶ
   - 一覧の「メインの右・縦置き」などは Windows のディスプレイ配置から求めた位置の目安
2. Display1 を **Windows** にして「1. キャリブレーション開始」。全画面の指示に従って点を見つめる
   - 前半: 17 点を**頭を動かさず目だけで**追う (約 40 秒)
   - 後半 (「頭を動かす点の数」が 5 か 9 のとき): 各点を見つめたまま、画面の指示どおりに「左右に回す → 上下にうなずく → 近づく・離れる」と 12 秒間頭を動かす。目は点から離さない。これで頭の向きと奥行きの補正を学習する (5 点で約 1 分)
   - 「座り直す姿勢数」を 3 以上にすると、上体ごと位置をずらして静止点を繰り返す。頭を動かす点を使うなら 1 で十分
   - 座り直しの指示画面では、1 周目の姿勢を基準に今の頭の位置を鏡のように表示する (緑の丸が今の頭、灰色の輪が目標、右のバーが奥行き)。「あと 4cm 左へ」のように残りが出て、目標に入って約 1 秒で自動的に次へ進む
   - 頭を動かすフェーズでは左右・上下・前後の 3 本のゲージが出る。緑が動かした範囲、枠が目標の振れ幅 (左右 ±20°、上下 ±15°、前後 ±6cm)。100% を目指す
   - カメラ映像には顔の輪郭・目・虹彩・頭の向きの軸 (赤 X、緑 Y、青 Z) を重ねて表示する
   - 終わるとプロファイルが保存され、「通常姿勢の誤差」と「頭を動かしたときの誤差」の目安がパネル下部に表示される
3. Display1 を **Switch** に切り替えて「2. トラッキング開始」。右にカメラ映像と推定点、下に fps や顔検出の状態が出る
4. 右上の「OBS ブラウザソース URL」を「コピー」し、OBS のブラウザソースに貼る
   幅・高さはキャプチャーボード映像と同じにして、そのソースの上に重ねる
5. 平滑化スライダーはトラッキング中に動かすと即反映される
6. **ワンキー補正**: プレイ中に画面中央の照準を見ながら補正キー (既定 F8) を押すと、その 0.5 秒間の視線の中央値を画面中央とみなしてずれを差し引く。「ピピッ」と鳴れば成功、低い音なら顔が取れていない。F9 で解除。座り直したり少しずれてきたら押し直す。キーは GUI で変更でき、`ctrl+f8` のような組み合わせも使える
6. 「ログからヒートマップを作成」で過去のログを画像化できる

設定は `settings.json` に保存され、次回起動時に復元されます。
以下はコマンドラインで使う場合の説明です。

### 1. キャリブレーション (座る位置・環境が変わるたびに)

1. Display1 の入力を **Windows** にする。マルチディスプレイの場合は「拡張」にして Display1 が Windows から見える状態にする
2. 普段プレイする姿勢で座る。**カメラと椅子はこの後動かさない**
3. `calibrate.bat 環境名 モニター番号` を実行 (例: `calibrate.bat home 0`)
   モニター番号は最初に一覧が出るので確認する
4. 全画面にカメラ映像が出るので顔が検出されている (Face OK) のを確認して SPACE
5. 出てくる点を順番に見つめる (16 点 + 中心、1 点 2 秒ほど)
6. 2 周目は「頭を少しずらして」と出るので、少し前後左右にずらした姿勢で同じことをする
   これで頭の動きに対する補正が効くようになります
7. 推定点がリアルタイムで表示されるので画面のあちこちを見て確認。良ければ SPACE で保存、R でやり直し

環境が 2 つあるなら `home`, `office` のように別名で保存してください。
プロファイルは `profiles/` に入ります。

### 2. 配信・録画

1. Display1 の入力を **Switch** に切り替える
2. `run.bat 環境名` を実行 (例: `run.bat home`)。カメラのプレビュー窓と fps が出ます
3. OBS でブラウザソースを追加
   - URL: `http://localhost:8766/`
   - 幅・高さ: キャプチャーボード映像と同じ (例 1920 x 1080)
   - キャプチャーボードのソースの **上** に置き、同じサイズ・位置に合わせる
4. 録画・配信を開始

終了はプレビュー窓で `q` か、コンソールで Ctrl+C。

OBS ブラウザソースの URL パラメータで見た目を変えられます。

```
http://localhost:8766/?color=ff3366&size=48&trail=800
```

| パラメータ | 意味 | 既定 |
|---|---|---|
| color | マーカー色 (16進) | 00e5ff |
| size | リング半径 px (1080p 基準) | 36 |
| trail | 軌跡を残すミリ秒 | 600 |
| debug=1 | 左下に接続状態と数値を表示 | off |

### 3. ログとヒートマップ (任意)

`logs/gaze_日時.jsonl` に毎フレームの視線が記録されます (Unix ミリ秒、正規化座標、まばたき等)。
OBS の録画ファイル名の日時と突き合わせれば映像と同期できます。

```bash
.venv\Scripts\python heatmap.py logs\gaze_20260921_203000.jsonl --start 60 --end 180
```

## コマンドラインオプション

```
python app.py
python calibrate.py --profile NAME --monitor N [--camera N] [--cam-res 640x480] [--grid 3|4] [--passes 2]
python run.py --profile NAME [--camera N] [--cam-res 640x480] [--preview] [--no-log] [--min-cutoff 1.0] [--beta 0.05]
```

- `--camera`: カメラが複数ある場合の番号 (0, 1, ...)
- `--cam-res`: カメラ解像度。720p だと 10fps しか出ないカメラがあるので既定は 640x480。30fps 出るなら 1280x720 の方が精度は上がる
- 部屋が暗いと自動露出でカメラの fps が落ちる (20fps 程度)。顔に光を当てると 30fps に戻る
- `--min-cutoff` を小さくすると滑らかになるが遅れる。`--beta` を大きくすると速い動きに追従する

## 精度と注意点

- Web カメラ方式の限界は視角 2〜4° 程度です。27 インチを 60cm で見ると画面上 2〜4cm の誤差になります
- 640x480 のカメラで顔が画面の 1/4 程度に映る状態だと、目の幅が約 30px、虹彩が約 10px しかなく、虹彩位置の推定に点ごとの系統誤差が乗ります (実測で幅の 5〜8%、約 100〜150px)。精度を上げる最も効く手は**目を大きく写す**ことです: 1280x720 で 30fps 出るカメラ (スマホなど) を使う、カメラを顔に近づける、望遠寄りのカメラを使う
- キャリブレーションの生データは `profiles/<名前>_calib.npz` に保存されます。`analyze_calib.py <名前>` で頭の動きの範囲や特徴量ごとの誤差を確認できます
- 頭を動かすフェーズで通常姿勢から yaw ±25°、pitch ±20°、前後 12cm を超えたサンプルは自動的に学習から除外されます (極端な姿勢では虹彩の検出が崩れるため)。ゲージの枠を大きく超えると白丸が赤くなります
  「画面のどの辺りを見ているか」は分かりますが、照準単位の精度は出ません
- キャリブレーション後に表示される「CV error」が目安です。幅の 5% 以下なら良好、10% を超えるならやり直し
- 精度を上げるコツ
  - 顔に正面から光が当たるようにする (逆光や画面の光だけの暗い部屋は不利)
  - カメラを目の高さに近づける (モニター上端で可)
  - 頭を大きく動かす人は `--passes 3` で姿勢を変えて 3 周する
  - メガネの反射で虹彩が取れないときは照明の位置を変える
- 座り直したら再キャリブレーション推奨 (30〜60 秒で終わります)
- 顔が検出できない・まばたき中はマーカーがフェードアウトします

## ファイル構成

```
gazetracker/
  dist/GazeTracker/GazeTracker.exe   ビルド済み exe (Python 不要)
  GazeTracker.pyw   コンソールなし起動 (setup.bat 後)
  GazeTracker.py    exe/pyw のエントリポイント (GUI / calibrate / heatmap を振り分け)
  build_exe.bat     PyInstaller で exe を作る
  setup.bat         初回セットアップ (pyw/bat 用)
  app.bat / app.py  操作パネル GUI 本体
  tracker/paths.py  exe と通常実行で保存先を切り替え
  calibrate.bat / run.bat   コマンドライン版のダブルクリック用
  calibrate.py      キャリブレーション画面
  run.py            リアルタイム推定 (コマンドライン版)
  tracker/engine.py 推定ループ + WebSocket/HTTP サーバー + ログ (GUI と CLI で共用)
  heatmap.py        ログからヒートマップ画像を作る
  download_model.py MediaPipe モデルの取得
  tracker/
    camera.py       カメラ読み込みスレッド
    features.py     MediaPipe から特徴量抽出、まばたき判定
    model.py        回帰モデルとプロファイルの保存・読込
    filters.py      One Euro Filter
  overlay/index.html  OBS ブラウザソース用オーバーレイ
  models/           face_landmarker.task
  profiles/         環境ごとのキャリブレーション結果
  logs/             視線ログ
```
