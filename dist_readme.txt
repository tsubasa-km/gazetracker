GazeTracker - Webカメラ視線トラッカー (OBS オーバーレイ対応)
====================================================================

■ 動作環境
  Windows 10/11 (64bit)、Webカメラ、OBS Studio 28 以降
  Python などのインストールは不要です。

■ セットアップ
  1. この zip を C:\GazeTracker のような短いパスのフォルダに展開する
     (パスが長すぎると起動時に DLL 読み込みエラーになります)
  2. cert\install_cert.bat を右クリック →「管理者として実行」
     (exe の署名を信頼させます。省略しても動きますが、警告が増えます)
  3. GazeTracker\GazeTracker.exe を起動
     SmartScreen の青い画面が出たら「詳細情報」→「実行」を一度だけ押してください

■ 使い方
  1. 左の「設定」でカメラを選び、「このカメラの映像を確認」で顔が正面に映るか確認
  2. 「モニターに番号を表示して識別」で、Switch を映すモニターの番号を選ぶ
  3. モニターの入力を Windows にして「1. キャリブレーション開始」
     前半は点を頭を動かさず目だけで追う。後半は点を見つめたまま画面の指示どおりに
     頭を動かす (左右に回す / 上下にうなずく / 近づく・離れる)。合わせて約 2 分
  4. モニターの入力を Switch にして「2. トラッキング開始」
  5. 「OBS ブラウザソース URL」をコピーし、OBS でブラウザソースを追加して貼る
     幅・高さはキャプチャーボード映像と同じにし、その上に重ねる
  6. プレイ中、画面中央の照準を見ながら F8 を押すとずれを補正 (F9 で解除)

■ コツ
  ・キャリブレーション中はカメラと椅子を動かさない。座り直したら取り直す
  ・顔に正面から光が当たると精度と fps が上がる
  ・目が大きく写るほど精度が上がる。1280x720 で 30fps 出るカメラ (スマホなど) を使うか、
    カメラを顔に近づける。640x480 では画面幅の 5〜8% 程度のずれが残る
  ・カメラが 720p で 10fps しか出ないときは「カメラ解像度」を 640x480 にする
  ・環境が複数あるときはプロファイル名を分ける (home / office など)

■ データの保存先
  プロファイル、ログ、設定は GazeTracker.exe と同じフォルダに保存されます。

■ 削除
  フォルダを削除するだけです。証明書の登録を消すには cert\uninstall_cert.bat を管理者として実行します。
